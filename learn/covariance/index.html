协方差与相关系数

理解共同变化方向，并避免把相关当作因果或独立。

协方差衡量两个变量相对各自均值的共同偏离。一起高于均值或一起低于均值，会产生正贡献；一高一低则产生负贡献。

相关系数用两个标准差把协方差标准化，介于 −1 和 1，描述线性关系方向和强度。任一标准差为 0 时，相关系数未定义。

零相关不意味着没有任何关系，也通常不能证明独立；相关也不能单独证明因果。检查散点图能发现非线性结构或异常点。

Cov(X,Y)=E[(X−μₓ)(Y−μᵧ)]
ρ = Cov(X,Y)/(σₓσᵧ)
  • ρ：rho，相关系数
  • Cov：协方差，受单位影响

逐步推导：每一步怎么来

中心化乘积与标准化

  1. 对有限二阶矩变量，定义Cov(X,Y)=E[(X−μₓ)(Y−μᵧ)]。展开为E(XY)−μₓμᵧ。

  2. 当σₓ、σᵧ都正，把变量各自标准化：U=(X−μₓ)/σₓ，V=(Y−μᵧ)/σᵧ。它们均值0、方差1。

  3. 定义相关系数ρ=E(UV)，提取常数得到ρ=Cov(X,Y)/(σₓσᵧ)。这解释了为什么除以两个标准差：消除原单位。

  4. 对任意实数t，0≤E[(U−tV)²]=1−2tρ+t²。取t=ρ，得到0≤1−ρ²，即−1≤ρ≤1。某个标准差为0时相关系数未定义。

计算题：从已知到答案

两个等可能状态下(X,Y)为(0,6)、(4,0)。求协方差和相关系数。

  1. μₓ=(0+4)/2=2，μᵧ=(6+0)/2=3。

  2. Var(X)=(4+4)/2=4，σₓ=2；Var(Y)=(9+9)/2=9，σᵧ=3。

  3. Cov(X,Y)=0.5×(−2)×3+0.5×2×(−3)=−6。

  4. ρ=−6/(2×3)=−1，表示本例中完全负向线性关系。

分步例题

两个变量标准差分别为 2、3，协方差为 −3，求相关系数。

  1. 检查两个标准差都不为零。
  2. 分母为 2×3=6。
  3. ρ=−3/6=−0.5。
  4. 这是负向线性关联，不能据此断言因果。
  • 零协方差或零相关通常不足以推出独立。

Covariance & correlation

Understand co-movement without confusing correlation with causation or independence.

Covariance measures how two variables deviate together from their means. Deviations with the same sign contribute positively, and opposite signs negatively.

Correlation standardizes covariance by both SDs and lies from −1 to 1. It describes linear association; it is undefined if either SD is zero.

Zero correlation does not rule out nonlinear dependence or generally establish independence. Correlation alone does not establish causation. A scatterplot can reveal nonlinear patterns and outliers.

Cov(X,Y)=E[(X−μₓ)(Y−μᵧ)]
ρ = Cov(X,Y)/(σₓσᵧ)
  • ρ: rho, correlation coefficient
  • Cov: covariance, which depends on units

Step-by-step derivation

Centered products and standardization

  1. For finite second moments, define Cov(X,Y)=E[(X−μₓ)(Y−μᵧ)]=E(XY)−μₓμᵧ.

  2. For positive SDs, standardize U=(X−μₓ)/σₓ and V=(Y−μᵧ)/σᵧ; each has mean 0 and variance 1.

  3. Define ρ=E(UV). Extracting constants gives ρ=Cov(X,Y)/(σₓσᵧ), which removes units.

  4. For every real t, 0≤E[(U−tV)²]=1−2tρ+t². Setting t=ρ yields ρ²≤1. Correlation is undefined if either SD is zero.

Calculation problem and worked solution

Two equally likely states give (X,Y)=(0,6) or (4,0). Find covariance and correlation.

  1. μₓ=(0+4)/2=2 and μᵧ=(6+0)/2=3.

  2. Var(X)=[(0−2)²+(4−2)²]/2=4, so σₓ=2. Var(Y)=[(6−3)²+(0−3)²]/2=9, so σᵧ=3.

  3. Cov(X,Y)=0.5×(−2)×3+0.5×2×(−3)=−6.

  4. ρ=−6/(2×3)=−1, a perfect negative linear relationship in this example.

Worked example

Two variables have SDs 2 and 3 and covariance −3. Find correlation.

  1. Check both SDs are nonzero.
  2. The denominator is 6.
  3. ρ=−0.5.
  4. This is negative linear association, not evidence by itself of causation.
  • Zero covariance or correlation generally does not imply independence.
