样本量与误差界

根据目标精度规划 n，并理解平方关系。

均值区间半宽 L≈zσ/√n，反解得到 n≈(zσ/L)²。实际样本量向上取整；规划时 σ 可能来自先导研究，需说明依据。

若希望误差界减半，样本量通常要变成 4 倍；置信水平越高，临界值越大，需要的样本越多。

比例规划使用 z²p*(1−p*)/L²。若没有合理先验比例，p*=0.5 给出这个公式下最保守的方差；它不能修复抽样偏差或保证回复率。

nmean=ceil[(zσ/L)²]
nproportion=ceil[z²p*(1−p*)/L²]
  • L：误差界，即区间半宽
  • ceil：向上取整

逐步推导：每一步怎么来

从误差界不等式反解n

  1. 均值z区间半宽M=z*σ/√n。规划要求M≤L，给定L>0、σ>0及临界值z*>0，先乘√n，再除L，得到√n≥z*σ/L。

  2. 两侧非负，平方保持方向：n≥(z*σ/L)²。n必须为整数，所以最小n=ceil[(z*σ/L)²]，ceil意为向上取整。

  3. 比例规划用预先选定p*估计未知波动，半宽M≈z*√[p*(1−p*)/n]。同样平方并解出n≥z*²p*(1−p*)/L²。

  4. 无先验信息时p(1−p)=1/4−(p−1/2)²≤1/4，故取p*=0.5给最保守的该近似样本量。

  5. 这些是独立抽样z方法的规划公式。σ只能估计时需说明规划值；t临界值随n变化，要迭代；有限总体、聚类与无应答还需另作设计调整。

计算题：从已知到答案

用规划临界值z*=1.96：均值规划σ=10、L=2；比例无先验信息、L=0.05。各至少需要多少有效独立观测？

  1. 均值：(1.96×10/2)²=9.8²=96.04。

  2. 向上取整n=97；半宽=19.6/√97≈1.9901≤2；n=96时半宽≈2.0004>2。

  3. 比例取p*=0.5：n≥1.96²×0.25/0.05²=0.9604/0.0025=384.16。

  4. 向上取整n=385，规划半宽=1.96√(0.25/385)≈0.049946，不超过0.05。

分步例题

规划 95% 均值区间，σ 估计为 10，期望半宽 L=2。

  1. 取 z≈1.96。
  2. zσ/L=1.96×10/2=9.8。
  3. 平方得 96.04。
  4. 向上取整至少 97 个有效独立观测，另考虑实际调查设计。
  • 题目给“总宽度”时要先除以 2 才是 L。

Sample size & margin of error

Plan n for a target precision and understand the square relationship.

For a mean interval, L≈zσ/√n implies n≈(zσ/L)². Round up the required size and justify any planning value of σ, perhaps from a pilot study.

Halving the margin generally requires four times the sample. Higher confidence increases the critical value and required n.

Proportion planning uses z²p*(1−p*)/L². With no reasonable planning proportion, p*=0.5 maximizes this variance term. It does not fix selection bias or guarantee a response rate.

nmean=ceil[(zσ/L)²]
nproportion=ceil[z²p*(1−p*)/L²]
  • L: margin of error, the half-width
  • ceil: round upward to an integer

Step-by-step derivation

Solving a margin-of-error inequality for n

  1. A mean z interval has half-width M=z*σ/√n. Requiring M≤L with positive inputs gives √n≥z*σ/L.

  2. Square the nonnegative sides to obtain n≥(z*σ/L)². The smallest integer is its ceiling.

  3. For a proportion, plan with p* and M≈z*√[p*(1−p*)/n]. Solve to obtain n≥z*²p*(1−p*)/L².

  4. Since p(1−p)=1/4−(p−1/2)²≤1/4, p*=0.5 gives the most conservative sample size within this approximation.

  5. These plan iid z intervals. A guessed σ is a planning input; t critical values depend on n and require iteration. Finite populations, clustering and nonresponse need design adjustments.

Calculation problem and worked solution

Use planning critical value 1.96. For a mean use σ=10, L=2; for a proportion use no prior information and L=0.05. Find both sample sizes.

  1. For the mean: (1.96×10/2)²=9.8²=96.04.

  2. Round up to 97. Its half-width is about 1.9901; n=96 gives about 2.0004 and fails.

  3. For the proportion, p*=0.5 gives n≥1.96²×0.25/0.05²=0.9604/0.0025=384.16.

  4. Round up to 385, giving planned half-width about 0.049946≤0.05.

Worked example

Plan a 95% mean CI with planning σ=10 and target half-width L=2.

  1. Use z≈1.96.
  2. zσ/L=9.8.
  3. Squaring gives 96.04.
  4. Round up to at least 97 valid independent observations, subject to survey design.
  • If given the total width, halve it before using L.
