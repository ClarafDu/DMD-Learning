线性回归逐步推导

  1. 课程模型假设误差独立、均值为零、同方差；正态性用于经典小样本推断。

  2. 估计斜率和截距后，残差向量满足两个独立约束，剩 n−2 个自由度。

  3. 残差是误差向量在剩余子空间的正交投影。同方差独立误差在每个正交方向的方差仍为 σ²，因此 E(SSE)=(n−2)σ²。

  4. 写成所需形式：s²=SSE/(n−2)；s=√s²

Error variance and regression output

The course model assumes independent, zero-mean, equal-variance errors. Normality supports classical small-sample inference.

The course model assumes independent, zero-mean, equal-variance errors. Normality supports classical small-sample inference.

Fitting an intercept and slope imposes two independent constraints on the residual vector, leaving n−2 degrees of freedom.

Residuals project the errors onto the remaining subspace. Independent equal-variance errors have variance σ² in each orthonormal direction, so E(SSE)=(n−2)σ².

s²=SSE/(n−2); s=√s²
  • ŷ: fitted value; y: observation; SSE: residual sum of squares.
  • b₀ is the intercept, bⱼ a slope; Sxx and Sxy are centered sums of squares and cross-products.

Step-by-step derivation

Linear regression derivation

  1. The course model assumes independent, zero-mean, equal-variance errors. Normality supports classical small-sample inference.

  2. Fitting an intercept and slope imposes two independent constraints on the residual vector, leaving n−2 degrees of freedom.

  3. Residuals project the errors onto the remaining subspace. Independent equal-variance errors have variance σ² in each orthonormal direction, so E(SSE)=(n−2)σ².

  4. Collect the terms: s²=SSE/(n−2); s=√s²
