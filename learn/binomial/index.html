二项分布与高尔顿板

检查四个条件，再计算成功次数的概率。

二项模型需要固定次数 n、每次仅成功或失败、成功概率 p 不变、各次独立。X 记录 n 次中成功的次数。成功只是标签，不一定是好事。

恰好 k 次成功包含多种次序。组合数 C(n,k) 计算这些次序的数量，再乘每种次序的概率 pᵏ(1−p)ⁿ⁻ᵏ。

高尔顿板中每一步向右的概率固定且独立时，最后位置由向右次数决定。改变 n 或 p，观察柱状分布形状与中心。

P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ
E(X)=np; Var(X)=np(1−p)
  • n：试验次数；k：目标成功次数
  • p：每次成功概率

逐步推导：每一步怎么来

计数推导与指示变量求矩

  1. 设n次独立伯努利试验，每次成功概率p。某个指定次序含k次成功、n−k次失败，其概率由独立性相乘为pᵏ(1−p)ⁿ⁻ᵏ。

  2. 选出k个成功位置：先有n(n−1)…(n−k+1)种有序选择，每个位置集合被k!种排列重复计数，故C(n,k)=n!/[k!(n−k)!]。

  3. 各次序互不重叠，概率相加，得到P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ。边界p=0或1直接按确定性试验解释，避免0⁰歧义。

  4. 令Iᵢ为第i次成功时取1、否则0的指示变量，则X=ΣIᵢ。E(Iᵢ)=p，E(Iᵢ²)=p，所以Var(Iᵢ)=p−p²。

  5. 期望线性性给E(X)=np；独立使所有交叉协方差为0，因此Var(X)=Σp(1−p)=np(1−p)。

计算题：从已知到答案

独立联系3名顾客，每位购买概率0.5。求恰好2人购买的概率、购买人数期望与方差。

  1. C(3,2)=3!/(2!1!)=3，指定次序概率0.5²×0.5=0.125。

  2. P(X=2)=3×0.125=0.375。

  3. E(X)=3×0.5=1.5人，这是模型均值，不要求是整数。

  4. Var(X)=3×0.5×0.5=0.75，SD(X)=√0.75≈0.8660人。

分步例题

独立联系 3 位顾客，每位购买概率 0.5，求恰好 2 位购买的概率。

  1. 检查 n=3、二分类、p=0.5、独立。
  2. 两位购买可按 买买不、买不买、不买买 三种次序发生。
  3. 每种次序概率为 0.5³=0.125。
  4. 相加为 3×0.125=0.375。
  • 不放回抽样通常会改变后续概率，不能自动当作独立二项试验。

Binomial distribution & the Galton board

Check four conditions before modeling a success count.

A binomial model needs fixed n, binary outcomes, constant success probability p, and independent trials. X counts successes; success is just a label.

Exactly k successes can occur in multiple orders. C(n,k) counts those orders and each has probability pᵏ(1−p)ⁿ⁻ᵏ.

On an ideal Galton board, independent steps with fixed rightward probability make the final slot a binomial count. Changing n or p changes the distribution shape and center.

P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ
E(X)=np; Var(X)=np(1−p)
  • n: trial count; k: target success count
  • p: success probability per trial

Step-by-step derivation

Counting and indicator-variable moments

  1. For n independent Bernoulli trials with success probability p, a specified sequence with k successes has probability pᵏ(1−p)ⁿ⁻ᵏ.

  2. There are n(n−1)…(n−k+1) ordered choices of success positions. Divide by k! repeated orders to get C(n,k)=n!/[k!(n−k)!].

  3. The sequences are disjoint, so P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ. Treat p=0 or 1 as deterministic boundary cases.

  4. Let Iᵢ indicate success. X=ΣIᵢ, E(Iᵢ)=E(Iᵢ²)=p and Var(Iᵢ)=p−p².

  5. Linearity gives E(X)=np. Independence removes cross-covariances, giving Var(X)=np(1−p).

Calculation problem and worked solution

Contact 3 independent customers with purchase probability 0.5 each. Find P(X=2), E(X) and Var(X).

  1. C(3,2)=3!/(2!1!)=3. Each relevant sequence has probability 0.5²×0.5=0.125.

  2. P(X=2)=3×0.125=0.375.

  3. E(X)=np=3×0.5=1.5 customers, a model mean that need not be an integer.

  4. Var(X)=np(1−p)=3×0.5×0.5=0.75; SD(X)=√0.75≈0.8660 customers.

Worked example

Contact 3 independent customers, each buying with probability 0.5. Find the probability exactly 2 buy.

  1. Check n=3, binary outcomes, p=0.5 and independence.
  2. Two purchases have three possible orders.
  3. Each order has probability 0.125.
  4. Add to obtain 0.375.
  • Sampling without replacement generally changes probabilities and is not automatically binomial.
